Responsive UI Mini-Components

Front-End Engineering Lab: Practical Assignment (Responsive Web Design)

Four responsive components built with HTML and CSS only, using a mobile-first approach with Flexbox, CSS Grid, media queries, transitions and keyframe animations.

Files
File	Component
task1.html	Product Showcase Card
task2.html	Responsive Pricing Cards
task3.html	Music Player & Playlist Shelf
task4.html	Creator Profile Header & Stats Card
How to Run

Open any taskN.html file in a browser. No installation is needed. To check the responsive layout, press F12, then Ctrl + Shift + M, and resize below and above 768px (850px for Task 2).
